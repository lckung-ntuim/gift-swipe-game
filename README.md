# 心動禮物大挑戰

仿交友軟體左右滑的禮物喜好小遊戲。商品庫 60 件，每輪隨機抽 20 件（同一支手機會優先抽沒看過的），
玩完依風格／價位／品類偏好，從「這輪沒出現、最好也沒看過」的商品中推薦一件。

## 檔案
- `index.html`：遊戲本體（最上方 `SHEET_ENDPOINT` 填 Apps Script 網址）
- `catalog.js`：內建商品清單（可直接在 GitHub 上編輯）
- `products.csv`：同一份清單，可匯入 Google 試算表「商品」分頁
- `apps-script/Code.gs`：貼到 Google 試算表的 Apps Script

## 設定 Google 試算表
1. 新建試算表 → 擴充功能 → Apps Script → 貼上 `Code.gs` → 儲存
2. 部署 → 新增部署作業 → 網頁應用程式（執行身分：我；存取權：所有人）→ 複製網址
3. 把網址填入 `index.html` 的 `const SHEET_ENDPOINT = "";`
4. 重新整理試算表，上方出現「🎁 禮物遊戲」選單

紀錄會寫入「總覽」（一輪一列）與「明細」（每件商品一列）。要 Excel：檔案 → 下載 → .xlsx。

## 更新商品／加照片（不用改程式）
1. 檔案 → 匯入 → 上傳 `products.csv` →「插入新工作表」，把分頁改名為 **商品**
2. 在「商品連結」欄貼上商品頁網址
3. 選單「🎁 禮物遊戲 → 依商品連結自動抓圖片」，會從商品頁抓主圖填入「圖片網址」
   （抓不到的列，到商品頁對圖片按右鍵「複製圖片網址」貼上即可）
4. 新增商品：新增一列、取一個新的 id；下架：「啟用」填「否」

規則：試算表裡同 id 的非空白欄位會覆蓋內建資料；沒有照片的商品會顯示示意圖；
沒填連結的商品會連到 Google 搜尋。修改後遊戲下次開啟就會生效，不必重新部署。
